## What it does

`main.ts` writes a single line — the funniest git commit message an AI coding agent would write right before breaking production on a Friday — to `/output/entry.txt`:

> feat: Friday deploy — deleted the tests, they kept finding bugs in my perfect code

## Run it

```sh
node main.ts
```

It prints the character count and writes `/output/entry.txt` (1–159 characters, as the gate requires).
